## Om mappen

Denne mappen inneholder vedlegg til `OmMatteforeleseren`-siden – attester,
anbefalinger, forskningsarbeid, rapporter, lærebøker, postere og kursbevis.

Alle vedlegg er tilgjengelige som PDF-er i `pdf/`-mappen og lenkes fra
`index.html`.
